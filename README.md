This project is an **AI Governance Engine** proof-of-concept, designed to automate and audit the credit risk assessment process in fintech models.

# Features
- Governance-as-Code (GaC): Automated evaluation of DG, TG, VG, RG, OG gates.
- Evidence Backbone: Immutable storage of gate results.
- Compliance Reporting: Exportable JSON reports for audit trails.
